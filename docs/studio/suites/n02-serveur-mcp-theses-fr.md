Banc d'essai du serveur MCP theses-fr, version 0.3 : search_theses, resolve_establishment, get_thesis, search_persons, list_facets et search_by_organisme. Les attendus ont été établis le 28/10/2026, en envoyant à l'API de theses.fr les requêtes que construit le serveur. Les effectifs bougent chaque jour : un écart de quelques unités sur un total n'est pas une erreur ; un écart d'ordre de grandeur, une thèse absente des résultats ou une thèse inventée en sont une. Chaque thèse citée doit l'être avec son lien theses.fr.
