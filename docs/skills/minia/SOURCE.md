# Source — Skills MinIA (production interne)

Skills créées ou adaptées par l'équipe projet. Chaque skill vit dans son propre dossier
`<nom>/SKILL.md` (voir le gabarit dans `_modeles/skill/SKILL.md`).

## Règles

- Une skill **adaptée** d'une skill externe indique son origine dans son front matter
  (`derived_from:` avec le chemin de la skill d'origine dans cette base et son URL source).
  On ne modifie jamais directement une collection importée.
- Chaque skill indique un `owner` (personne référente) et une `version`.
