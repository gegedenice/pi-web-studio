# Cartographie des courants théoriques

Cartographie les principaux courants théoriques qui traitent de [concept]. Présente-les sous forme de tableau comparatif : courant, hypothèse centrale, auteurs fondateurs, méthode dominante, principale critique adressée. N'invente aucune référence ; signale les zones où tu n'es pas sûr.
