# Tableau de synthèse comparatif

Construis un tableau de synthèse comparant ces travaux sur [thème] : [liste]. Colonnes : auteur (année), question, terrain/échantillon, méthode, résultat principal, limite. Ajoute une dernière colonne « ce que mon étude ajoute ».
