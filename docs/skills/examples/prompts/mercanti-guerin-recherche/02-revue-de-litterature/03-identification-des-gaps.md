# Identification des gaps

À partir de cette synthèse de littérature [coller la synthèse], identifie les lacunes de recherche réelles : (1) ce qui n'a jamais été étudié, (2) les résultats contradictoires non tranchés, (3) les contextes/populations sous-explorés. Pour chaque lacune, formule la question de recherche qu'elle ouvre.
