# Synthèse critique d'un corpus

Voici les résumés de [n] articles : [coller]. Produis une synthèse critique, pas un catalogue : regroupe par convergences et divergences, hiérarchise les apports, et dégage le fil argumentatif qui traverse le corpus. Distingue ce que disent les sources de ce que j'en infère.
