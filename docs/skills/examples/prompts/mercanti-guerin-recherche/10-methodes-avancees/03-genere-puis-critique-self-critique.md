# Génère puis critique (self-critique)

Produis d'abord une réponse à [tâche]. Ensuite, change de casquette et critique-la sévèrement comme un évaluateur externe : failles, angles morts, sur-affirmations. Enfin, produis une version révisée intégrant tes propres critiques.
