# Vérifier une référence (anti-hallucination)

Voici une référence que je compte citer : [coller]. Ne la valide pas par défaut. Indique ce qui est vérifiable, ce qui ne l'est pas, et signale tout signe d'invention (DOI improbable, revue inexistante, appariement auteur/titre douteux). Conclus par : à vérifier sur la source primaire / probablement fiable / suspecte.
