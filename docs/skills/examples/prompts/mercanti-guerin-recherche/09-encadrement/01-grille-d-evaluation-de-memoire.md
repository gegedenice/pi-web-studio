# Grille d'évaluation de mémoire

Construis une grille d'évaluation pour un mémoire de Master [mention]. Critères pondérés : problématique, ancrage théorique, méthode, analyse, contribution managériale, forme. Pour chaque critère, décris les niveaux insuffisant / satisfaisant / excellent.
