# Échantillonnage et saturation

Pour une étude [quali/quanti] sur [thème], conseille-moi sur l'échantillonnage : stratégie, taille, critères d'inclusion, et comment justifier la saturation (quali) ou la puissance statistique (quanti). Précise les limites de transférabilité.
