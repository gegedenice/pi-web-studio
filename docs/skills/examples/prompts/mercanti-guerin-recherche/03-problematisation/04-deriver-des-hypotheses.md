# Dériver des hypothèses

À partir de ce cadre théorique [coller], dérive 3 à 5 hypothèses testables. Pour chacune : énoncé directionnel, fondement théorique (auteur, année), et variable d'opérationnalisation. Signale toute hypothèse qui serait sous-déterminée par la théorie.
