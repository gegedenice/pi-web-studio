# Aide-moi à penser

J’ai utilisé NotebookLM pour extraire les éléments suivants de [N] sources sur [SUJET] : [COLLER LES EXTRAITS : matrice, carte, lacunes, hypothèses, etc.]. Contexte : la problématique [DÉCRIRE] ; ce que je sais déjà [LISTE] ; ce que je veux produire [ARTICLE / CADRE / DISCUSSION / MODÈLE] ; l’échéance [DATE]. Fais maintenant ce que NotebookLM ne peut pas faire : 1) les 3 insights les plus importants enfouis dans ces extraits (pas des thèmes — des insights) ; 2) l’argument que ces sources construisent collectivement ; 3) les contradictions à résoudre ; 4) l’angle mort : ce qui manque et que je dois chercher ; 5) l’insight qui change ma problématique ; 6) la synthèse en 3 phrases pour un collègue ; 7) la question de suivi à réimporter dans NotebookLM. NotebookLM m’a donné la bibliothèque. Maintenant aide-moi à penser.
