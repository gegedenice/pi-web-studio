# Architecture des relations entre concepts

À partir de la carte mentale et des sources, identifie les concepts centraux pour comprendre [MON PHÉNOMÈNE]. Pour chaque concept : définition la plus répandue | niveau d’abstraction (macro/méso/micro) | relations logiques avec les autres (précède, succède, modère, médie, s’oppose). Propose une organisation sous forme de schéma textuel : X → Y → Z, X modère Y, etc. Sois explicite sur ce qui est dans les sources et ce qui relève de ta proposition.
