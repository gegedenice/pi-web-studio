# Première version du modèle conceptuel

Propose une première version de modèle conceptuel pour étudier [MON PHÉNOMÈNE] : 1) construits exogènes (antécédents), 2) construits endogènes (conséquences), 3) médiateurs éventuels, 4) modérateurs éventuels, 5) relations directionnelles (→, ←, ↔), 6) pour chaque relation, au moins une source du corpus qui la soutient. Présente d’abord une description textuelle : X → Y (soutenu par Dupont 2022) ; Z modère X → Y (soutenu par Smith 2021). Puis une description schématique ASCII simple.
