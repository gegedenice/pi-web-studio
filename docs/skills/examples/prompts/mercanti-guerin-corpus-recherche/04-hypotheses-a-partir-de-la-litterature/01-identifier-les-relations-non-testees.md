# Identifier les relations non testées

Dans ce corpus, quelles relations entre variables ou concepts sont fréquemment mentionnées mais jamais empiriquement testées ? Pour chaque relation : variables impliquées | articles qui la mentionnent | pourquoi elle n’a pas été testée | faisabilité d’un test empirique. Termine par un classement des trois relations les plus prometteuses pour une hypothèse de recherche.
