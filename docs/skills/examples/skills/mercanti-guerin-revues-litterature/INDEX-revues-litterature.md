# Famille de skills « Revues de littérature » — Index et arbre de décision

13 skills couvrant la typologie de Grant & Booth (2009, 14 types, consolidés) + les protocoles propres aux sciences de gestion (SPAR-4-SLR, TCCM/ADO, bibliométrie selon Donthu).

## Arbre de décision : quel skill pour quelle situation ?

**Quelle est la nature de la question ?**

1. **Question fermée : « que sait-on de la relation X→Y ? »**
   - Synthèse narrative des résultats, protocole documenté → `revue-systematique` (PRISMA 2020 / SPAR-4-SLR)
   - Les études sont quantitatives et commensurables → `meta-analyse`
   - Corpus quali + quanti à intégrer → `revue-mixte` (MMAT)
   - Beaucoup de revues systématiques existent déjà → `umbrella-review` (AMSTAR 2, CCA)
   - Délai court, livrable décisionnel → `rapid-review`

2. **Question ouverte : « qu'est-ce qui existe sur X ? » (champ émergent)**
   - Cartographier étendue, définitions, lacunes → `scoping-review` (PRISMA-ScR ; variante mapping)
   - Corpus très large, structure par citations/mots-clés → `revue-bibliometrique` (Donthu, VOSviewer/Bibliometrix)

3. **Question explicative : « pourquoi ça marche ici et pas là ? »**
   - Mécanismes contextuels d'interventions complexes → `realist-review` (CMO, RAMESES)

4. **Question interprétative : « que disent les expériences vécues ? »**
   - Corpus d'études qualitatives → `meta-synthese-qualitative` (méta-ethnographie, ENTREQ)

5. **Question conceptuelle : « comment repenser le champ ? »**
   - Évaluer/critiquer et proposer un modèle → `revue-critique`
   - Croiser des littératures disciplinaires en cadre unifié → `revue-integrative` (Whittemore & Knafl, Torraco)

6. **Revue au service d'un texte (article empirique, thèse, essai)**
   - Section théorique argumentée, sélective → `revue-narrative` (variante state-of-the-art)

7. **Structurer la synthèse d'un corpus déjà constitué**
   - Cadre TCCM / ADO / 6W + agenda en RQ → `revue-cadre-tccm`

## Workflows hybrides fréquents en gestion

- `revue-bibliometrique` → `revue-systematique` : cartographie du champ, puis SLR sur les clusters.
- `revue-systematique` → `revue-cadre-tccm` : protocole PRISMA pour le corpus, TCCM pour la synthèse (format IJCS/JBR).
- `scoping-review` → `revue-systematique` : la scoping établit la faisabilité de la SLR.
- Tout skill → `abstract-recherche` + `introduction-recherche` + `research-humanizer` pour la mise en article.

## Correspondance avec les 14 types de Grant & Booth (2009)

| Type Grant & Booth | Skill |
|---|---|
| Systematic review | revue-systematique |
| Systematized review / Systematic search & review | revue-systematique (versions allégées : documenter les écarts) |
| Meta-analysis | meta-analyse |
| Scoping review | scoping-review |
| Mapping review / systematic map | scoping-review (variante mapping) |
| Literature review (narrative) | revue-narrative |
| State-of-the-art review | revue-narrative (variante) |
| Critical review | revue-critique |
| Overview | revue-narrative ou umbrella-review selon le sens |
| Umbrella review | umbrella-review |
| Rapid review | rapid-review |
| Qualitative systematic review / evidence synthesis | meta-synthese-qualitative |
| Mixed studies / mixed methods review | revue-mixte |
| — (hors typologie 2009) | realist-review, revue-integrative, revue-bibliometrique, revue-cadre-tccm |
