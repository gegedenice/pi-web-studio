# Rapid review

La rapid review est une revue systématique **sous contrainte de temps assumée** : mêmes principes (question explicite, recherche documentée, sélection à critères, synthèse structurée), mais avec des raccourcis méthodologiques **choisis, déclarés et dont les conséquences sont discutées**. La différence entre une rapid review et une revue bâclée tient en un tableau : celui des simplifications adoptées.

Usage type : éclairer une décision datée — note pour un décideur, cadrage d'appel à projets, due diligence, positionnement rapide sur un sujet chaud (réglementation IA, nouvelle plateforme...).

## Étape 1 — Négocier le mandat

Trois paramètres à fixer avec l'utilisateur avant tout :
1. **La question**, la plus étroite possible : la rapid review ne survit pas aux questions larges. Resserrer population, contexte, période.
2. **Le délai et le livrable** : note de 3 pages ? synthèse de 15 pages ? Cela dicte les raccourcis.
3. **Le destinataire** : décideur (implications d'abord) ou chercheur (méthode d'abord).

## Étape 2 — Choisir les raccourcis (menu Cochrane Rapid Reviews)

Chaque raccourci s'adopte explicitement ; les documenter dans un tableau « simplification → risque induit » :

| Levier | Version complète | Raccourci rapid | Risque |
|---|---|---|---|
| Bases | 4–6 bases | 1–2 (ex : Scopus seul) | Couverture partielle |
| Période | Toute la littérature | 5–10 dernières années | Perte des fondateurs |
| Langues | Multilingue | EN (+ FR) | Biais géographique |
| Types de sources | Tout | Revues à comité + 1–2 revues systématiques récentes comme socle | Dépendance aux synthèses d'autrui |
| Screening | Double lecture indépendante | Simple lecture + validation d'un échantillon | Erreurs de sélection |
| Qualité | Grille complète par étude | Évaluation simplifiée (classement de revue + design) | Sur/sous-pondération |
| Extraction | Grille exhaustive | Champs essentiels seulement | Nuances perdues |

Astuce structurante : **s'appuyer d'abord sur les revues systématiques existantes** (mini-umbrella) et ne remonter aux études primaires que pour la période non couverte par ces revues.

## Étape 3 — Exécution compressée

Même chaîne qu'une SLR, comprimée : équation simple mais documentée → screening → extraction dans une grille courte → synthèse. Tenir le décompte du flux (même simplifié : identifiés / exclus / inclus) — c'est ce qui distingue le format d'une compilation.

## Étape 4 — Synthèse orientée décision

Structure type du livrable :
1. **Réponse en une page** (executive summary) : ce que la littérature établit, avec le niveau de confiance.
2. Ce qui est solide / ce qui est débattu / ce qu'on ne sait pas — trois rubriques, pas plus.
3. Implications pour la décision en jeu.
4. **Encadré méthodologique** : question, sources, période, tableau des simplifications et de leurs risques.
5. Références.

Calibrer la confiance dans les formulations : une rapid review dit « les éléments disponibles suggèrent », pas « il est démontré que ».
