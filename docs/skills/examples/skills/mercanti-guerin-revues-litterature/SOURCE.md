# Source — Skills « Revues de littérature » (Maria Mercanti-Guérin)

Pack de 13 skills Claude, un par type de revue de littérature, plus un guide de choix.
Chaque skill encode la méthodologie d'un format de revue : étapes, standards de reporting,
erreurs à éviter, checklist finale.

## Provenance et méthode d'extraction

- Page de présentation : <https://mariamercantiguerin.com/revues-de-litterature-et-skills-claude/>
- Archive téléchargée : `skills-revues-litterature-complet.zip` (39 391 octets, SHA-256 ci-dessus)
- Chaque fichier `.skill` de l'archive est lui-même une archive ZIP contenant un unique
  `<nom>/SKILL.md`. Ce fichier a été extrait **sans aucune modification**, d'abord aplati
  en `<nom>.md` puis, le 2026-10-26, replacé dans la structure d'origine `<nom>/SKILL.md`
  (format standard des skills, installable tel quel). Le frontmatter YAML (`name`,
  `description`) est conservé.
- `INDEX-revues-litterature.md` est repris tel quel depuis la racine de l'archive.
