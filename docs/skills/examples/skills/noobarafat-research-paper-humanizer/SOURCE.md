# Source — Research Paper Humanizer (noobarafat)

Skill de réécriture stylistique de textes académiques rédigés avec assistance IA (style IEEE,
revues Q1) : elle vise un phrasé plus naturel en conservant le sens, les chiffres, les
citations, la terminologie et le registre formel.

## ⚠️ Avertissement d'usage

L'objectif déclaré par l'auteur est de **faire baisser les scores des détecteurs de texte IA**.
Dans cette base, la skill est retenue uniquement comme outil d'amélioration du style :

- elle ne dispense pas de **déclarer l'usage de l'IA** lorsque la revue ou l'établissement
  l'exige (voir le prompt `prompts/mercanti-guerin-corpus-recherche/06-declaration-dusage-ia-section-methode`) ;
- l'auteur·rice reste responsable de vérifier l'intégralité du contenu réécrit
  (sens, chiffres, références) — la skill elle-même le rappelle.

Elle peut s'enchaîner après `abstract-recherche` (structure puis phrasé). Attention : la skill
compagnon citée par `abstract-recherche` s'appelle `research-humanizer` ; rien n'indique qu'il
s'agisse de celle-ci.
